# SubDL Arabic Plugin for CloudStream

Plugin to fetch and download Arabic subtitles from SubDL.

## Installation
1. Open CloudStream app.
2. Go to Settings → Plugin repositories.
3. Add this URL:
   ```
   https://raw.githubusercontent.com/anastoji99-beep/cloudstream-subdl-arabic/main/plugins/index.json
   ```
4. Install “SubDL Arabic” from the plugin list.
